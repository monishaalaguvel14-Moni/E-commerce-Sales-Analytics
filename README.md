# Ecommerce Sales Analysis Using Excel

## Project Overview
This project focuses on analyzing E-commerce sales data using Microsoft Excel to understand sales performance, customer behavior, and business trends.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Dashboard
- Data Cleaning
- Data Visualization

## Project Objectives
- Analyze overall sales performance.
- Identify top-selling products.
- Understand customer purchasing patterns.
- Analyze monthly and yearly sales trends.
- Identify profitable product categories.
- Create an interactive sales dashboard.

## Project Files
- `Ecommerce_Sales_Analysis.xlsx` – Excel workbook containing the sales data, analysis, charts, and dashboard.
- `Ecommerce_Sales_Report.pdf` – Project report.
- `Dashboard_Screenshot.png` – Dashboard preview.
